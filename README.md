# What to Do in Tulum

A visitor guide from [Lighthouse Church Tulum](https://www.lighthousechurch.com.mx): beaches, cenotes, ruins, where to eat and practical tips.

Live at **https://lighthousetulum.github.io/things-to-do/** (linked from our Linktree).

## Updating

- Edit `index.html` (all text, styles and the logo are in this one file).
- Commit to `main`; GitHub Pages republishes automatically within a minute or two.
- To refresh the PDF, open the page in Chrome/Brave → Print → Save as PDF (Letter, no headers/footers, background graphics on) and replace `What-to-do-in-Tulum.pdf`.
